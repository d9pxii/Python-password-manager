# 🔐 Python Password Manager

Простое и удобное десктопное приложение на Python для локального хранения паролей, пин-кодов и заметок.

## ✨ Возможности

* **Разделение по категориям:** отдельные вкладки для личных данных, сайтов/сервисов, программ и текстовых заметок.
* **Локальное хранение:** все записи сохраняются в базу данных SQLite (`passdb.db`), которая автоматически создается при первом запуске.
* **Удобный просмотр и управление:** отдельное окно со списком сохраненных данных, быстрым копированием пароля и удалением записей с подтверждением.
* **Современный интерфейс:** темная тема, выполненная на базе библиотеки `customtkinter`.

## 🛠 Технологии

* **Python 3**
* **CustomTkinter** — современный графический интерфейс
* **SQLite3** — локальная база данных
* **Pillow (PIL)** — работа с иконками интерфейса

## 🚀 Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   cd Python-password-manager
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Запустите приложение:**
   ```bash
   python main.py
   ```

## 📁 Структура проекта

```text
passwordmanager/
├── img/               # Иконки для вкладок меню
├── main.py            # Главный файл с интерфейсом приложения

└── .gitignore         # Исключение локальной БД и кэша из Git
```
